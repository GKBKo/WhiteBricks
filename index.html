실시간 자동 동기화

처음 한 번 Firebase를 설정하면 같은 Google 계정의 기기 사이에서 자동으로 동기화됩니다.

Firebase 연결 설정

Firebase 설정은 브라우저에 저장됩니다. 서비스 계정 키나 비공개 키는 입력하지 마세요.

글·사진·카테고리를 자동 저장하고 다른 기기의 변경을 받습니다. 오프라인 수정은 같은 계정으로 재연결할 때 전송합니다. 같은 글을 동시에 고치면 충돌 사본을 보관합니다.

처음 한 번 설정하는 방법
  1. Firebase Console에서 기존 WhiteBrick Google Cloud 프로젝트를 연결합니다.
  2. 프로젝트 설정 → 내 앱 → 웹앱을 추가합니다. Firebase Hosting은 설정하지 않아도 됩니다.
  3. 빌드 → Authentication → 로그인 방법에서 Google을 사용 설정하고 지원 이메일을 선택합니다. 설정 → 승인된 도메인에 gkbko.github.io를 추가합니다.
  4. 빌드 → Realtime Database를 만들고 잠금 모드로 시작합니다. 규칙 탭에 이 보안 규칙의 내용을 붙여넣고 게시합니다. Cloud Firestore가 아니라 Realtime Database를 선택합니다.
  5. 프로젝트 설정 → 웹앱의 firebaseConfig를 위 칸에 붙여넣습니다. databaseURL이 없으면 Realtime Database의 HTTPS 주소를 추가합니다.
  6. 설정 저장 → Google 로그인 → 이 기기 기존 기록 합치기를 누릅니다. 다른 기기에서도 같은 프로젝트 설정과 같은 Google 계정을 사용합니다.

최초 연결 전 JSON 백업을 받아 두세요. 기존 Drive 자료는 기존 서가에서 불러온 뒤 백업 가져오기로 옮길 수 있습니다. 기존 Drive 파일은 자동 삭제하지 않습니다.

연결하면 이 기기의 기록과 Drive 기록을 합칩니다.

연결 로그 
아직 연결 기록이 없습니다.

세 값은 입력할 때마다 이 브라우저에 자동 저장됩니다. PC와 모바일에서는 각각 한 번 입력해 주세요. 연결 로그와 Drive 기록에는 설정값을 넣지 않습니다.

처음 한 번 설정하는 방법
  1. Google Cloud Console에서 한 프로젝트에 Google Drive API와 Google Picker API를 사용 설정합니다.
  2. Google Auth Platform에서 로그인할 계정을 테스트 사용자로 추가합니다. 웹 애플리케이션 유형의 OAuth 클라이언트를 만들고 승인된 JavaScript 원본에 을 넣습니다.
  3. 같은 프로젝트에서 API 키를 만들고, 웹사이트 제한에는 위 주소의 /* 경로를, API 제한에는 Google Picker API를 설정합니다. 프로젝트 ID 대신 프로젝트 번호를 복사하세요.
  4. 위 세 값을 입력하고 Google 계정을 연결합니다. 선택기가 열리면 지정 폴더를 고르세요. PC와 모바일에서 같은 프로젝트 설정과 같은 Google 계정을 사용합니다.

Google 인증이 만료되거나 앱을 다시 열면 연결 버튼으로 재연결합니다. 오프라인에서 수정한 기록은 이 기기에 남고 다음 연결 때 전송됩니다.

모바일 앱 설치와 공유

Android Chrome에서 메뉴의 앱 설치 또는 홈 화면에 추가 → 설치를 선택하세요. X의 시스템 공유 메뉴에서 나의 읽기 서가를 선택하면 새 기록이 열립니다.

iPhone은 Safari 공유 메뉴에서 홈 화면에 추가할 수 있습니다. X에서 링크를 복사하고 새 기록에서 붙여넣으세요.

iPhone 공유 단축어 설정

단축어 앱에서 서가에 저장을 만들고 공유 시트에서 보기를 켜세요. 입력 유형은 URL과 텍스트를 선택합니다.

공유 입력을 URL 인코딩한 뒤, 텍스트 동작에 를 넣고 바로 뒤에 인코딩 결과 변수를 붙이세요. 이어서 URL 열기로 해당 텍스트를 엽니다.

X에서 시스템 공유 메뉴를 열고 서가에 저장을 선택하면 브라우저에서 새 기록이 열립니다.
